# Expense Tracker

A simple and responsive browser-based Expense Tracker that helps users manage their income and expenses.

## Features

- Add income and expenses
- Current balance calculation
- Total income and expense tracking
- Current month expense chart
- Monthly income and expense overview
- View transactions from all months
- Filter transactions by income or expense
- Delete transactions
- Low balance alert
- Data saved using LocalStorage
- Responsive design
- Indian Rupee (₹) currency support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- LocalStorage

## Expense Categories

- Other

- Salary
- Freelance

- Other

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
